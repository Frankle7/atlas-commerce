# MISSION-000 — Project Foundation

## Objetivo

Configurar a fundação inicial do Atlas Commerce, estabelecendo a estrutura mínima necessária para o desenvolvimento do projeto.

---

## Contexto

A Missão 000 representa a etapa inicial do projeto.

Seu objetivo é preparar o repositório, o backend, a infraestrutura local, o banco de dados e a documentação necessária para que as próximas missões possam ser executadas sobre uma base organizada e versionada.

Esta missão não implementa funcionalidades de negócio.

Ela estabelece a fundação técnica do projeto.

---

## Entregas

- Estrutura inicial do repositório
- Estrutura inicial do Spring Boot
- Configuração Maven
- PostgreSQL em ambiente Docker
- Docker Compose
- Estrutura inicial de banco de dados
- Arquitetura inicial de pacotes
- Documentação técnica
- Ambiente de desenvolvimento
- Configuração inicial de versionamento Git
