# Atlas Commerce

Projeto desenvolvido para simular um e-commerce enterprise utilizando arquitetura baseada em Domain Driven Design, Clean Architecture e boas práticas utilizadas em grandes empresas.

## Stack

- Java 21
- Spring Boot
- PostgreSQL
- Docker
- Flyway
- JWT
- Flutter Web
- GitHub Actions

## Arquitetura

- Modular Monolith
- REST API
- Repository Pattern
- DTO Pattern
- Mapper Pattern
- UUID
- JWT Authentication
